## 安卓空白页的实测

- 旧网站的 HTML 和主脚本在线均返回 200。使用 Chromium 79 的本地测试加载旧发布包时，控制台报告 `Unexpected token '?'`，React 没有挂载，标题停在初始 HTML 的「小学与高中英语学习室」。
- 同一个 Chromium 79 加载修复包后，成功渲染高中首页并更新标题。用 393 × 852 的触屏视口检查了小学首页、阅读练习、命题设置和两款游戏的启动与暂停。现代浏览器另测了主脚本下载失败后点重试，以及脚本延迟超过提示时间后自行恢复。
- 在隔离的浏览器会话内，用模拟错题走通了「错题本 → 按错题去命题」。传输检查确认只包含知识点，四年级看不到三年级的错题。在线服务也用虚构的宠物主题成功返回了一套四题的小学阅读练习。
- 用一段自拟的英文短文在线提交高中作文批改，拿到回执后刷新了页面。在「取回上次批改」中取回评分和评语，网络日志只记录到一次任务提交，回执中没有作文正文。
- 用户手机的具体 WebView 版本和当时的网络状况尚未获得。模拟复现说明兼容问题确实存在，仍需该手机重新打开后确认其表现。
