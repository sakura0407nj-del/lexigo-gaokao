# 小学词库扩充与教材索引的来源边界

核对日期：2026-11-21。系列限定为人教版英语 PEP（三年级起点），不混入精通版或一年级起点教材。

## 数据是什么

- `data/primary-words.json` 原240条及学习ID完全保留。本次校验统一换行为LF后的SHA-256为 `4d0254a7977854817aded975ade350dbc82b4e71a6d82c482ba05a0a3bef00bf`，兼容Windows检出时自动转换CRLF。
- `data/primary-expanded-source.tsv` 是本次独立编写的学习资料。每条包含建议年级、主题、词目、语境词性、中文释义、原创英文例句和原创中文解释。建议年级是学习分层，不表示该词首次出现于某年级教材。
- `data/primary-expanded-words.json` 从上述资料生成，本次新增475条，总计715条，新增ID为 `px-` 加稳定词目标识。原有词不重新编号。词性对应所给例句；数词、介词等不应混入仅考名词、动词、形容词和副词的游戏。
- `data/primary-textbook-evidence.json` 只记录有限的英文词目—单元事实、来源链接和核对边界。`data/primary-textbook-index.json` 将词目解析为全局 `wordIds`。同一个词可出现在多册、多单元。选教材时应直接按这些ID解析，不能先按词卡的建议年级过滤。
- `data/primary-spelling-variants.json` 是听写可接受的拼写形式，含旧ID的旁路元数据。不会以同义词替换拼写要求，也没有臆造缩写。新增卡片同时携带适用的 `accepted` 数组。

原有240条是之前的学习内容；本次新增释义和例句由Codex独立编写与审校，不声称摘自教材或由此次Gemini调用生成。未为缺音标的词补造音标，也未给这些词编造词频或高考频率。

`over` 在表示事件结束的表语用法中，权威词典有副词和形容词两种分析，因此保留两类，不进入要求唯一词性的游戏。词性参考见 [Cambridge over](https://dictionary.cambridge.org/dictionary/english/over)；`must` 按 [Cambridge modal verb](https://dictionary.cambridge.org/dictionary/english/must) 归入动词大类并注明情态动词。没有抄用词典例句。

## 版本与覆盖程度

[人教社2024年新教材简介](https://www.pep.com.cn/xw/zt/hd/12/xjcjs/xx/202409/t20240920_1995564.html)介绍了修订系列。[人教社三上当前配套目录](https://www.pep.com.cn/zslth/yyptzy/xypep/3s/)与[六上旧配套目录](https://www.pep.com.cn/zslth/yyptypzj/xypep/6s/)同时存在，不能把官网路径、访问日期或“2024新版”的第三方标题当作全部册次已经换版的证明。

新版索引覆盖三上、三下、四上、四下、五上、五下、六上，每册均为 **部分已核**。官方配套资源用于核对单元名称；具体词目另与可见的逐词页面交叉核对。尚未逐页复核官方词汇附录，不能显示“官方完整词表已核”或保证适配所有印次。

六下独立归入修订前旧版。核对实际下载的教材镜像版权页、目录和印刷页54–56后，确认所核版本为2014年10月第1版、2017年11月第4次印刷，ISBN 9787107290718。此前华南师大公开教研资料中所写“2014年3月”不作为本索引版本依据。四个单元均有有限词目可练；新版六下未在本次索引中伪造。每个单元的覆盖和出处见JSON中的 `note`、`verification`、`sourceIds`。

## 核对方法与排除的问题

实际下载的参考资料保存在忽略发布的 `work/primary-source-check/`：包括8册旧版社区JSONL、30个新版单元公开HTML和一份六下旧版教材镜像，并有URL、下载时间及SHA-256记录。官方PEP页面/PDF的本地直连在本次环境出现TLS EOF；其可见目录通过网页检索工具核对。镜像下载不等于官方授权，没有声称已从官网取得完整原书，也没有逐页审完八册教材。

旧版社区文件没有可靠单元字段，且有六上词错放六下、`wear.` 带句点等问题，因此没有按顺序平均分单元，也没有把849条上游记录整包发布。社区项目中的MIT代码许可证不等同于其转录教材或词典数据取得再分发授权。

第三方词目页面仅提供有限的词目归属事实，本次不复用其中文释义、例句、音频、黑白体要求或完整顺序。发布索引内词目按字母排序，自主释义和例句独立编写；没有再分发原书PDF、长段教材文字或不明许可的成套编排。

核对不只检查单词拼写。已排除或替换不适合现有词卡语境的同形词关联，例如 `May`（五月）与 `may`（可能）、`milk`（牛奶）与“挤奶”、`cook`（做饭）与“厨师”、`light`（灯）与“照亮”、`cool`（凉爽）与“冷却”、`run`（跑）与“运转”。旧版过去式练习也不把 `read` 的现在式读音直接当成过去式读音。教材词汇本身可能存在多义，排除仅表示当前学习卡语境不足，不表示教材没有该词。

## 构建与回归

```sh
node scripts/build-primary-expansion.mjs
node scripts/build-primary-expansion.mjs --check
node scripts/build-primary-expansion.mjs --csv work/primary-learning-index.csv
node scripts/check-primary-expansion.mjs
```

CSV只导出已选择的学习事实与本项目学习卡内容。构建脚本不自动联网复制教材，也不会把只有资料标题的记录升级为已核词目。回归覆盖旧240条不变、新ID与拼写唯一、例句含词及基本质量、建议年级与教材归属独立、版本隔离、同形异义防误匹配、来源完整性、拼写变体和确定性重建。
